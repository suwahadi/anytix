# antislop audit 001: halaman publik Fase 1

Tanggal: 17 Oktober 2026. Mode: AFTER (session override). Cakupan: `/`, `/events` (pencarian, filter, empty state), `/events/[slug]`, `/events/[slug]/tickets`, `/terms`, `/privacy`, halaman 404.

- R-17 PASS: angka yang tampil (jumlah event per kategori, harga, sisa tiket) berasal dari database.
- R-18 PASS: tidak ada testimoni.
- R-23 PASS: logo berupa teks nama situs sesuai spec; logo asli bisa diunggah dari Pengaturan Situs.
- R-24 PASS: header hanya berisi "Jelajah Event" (`/events`); footer menuju `/terms` dan `/privacy` yang ada.
- R-25 PASS: semua pasangan teks dan latar diukur di kedua tema; terendah 4.84 (`#b45309` di atas `#fffbeb`, badge "Hampir habis"), diverifikasi dengan contrast checker antislop.
- R-26 PASS: "Beli Sekarang" sengaja nonaktif dengan label terlihat "Pembayaran dibuka di tahap berikutnya." Kontrol lain punya aksi nyata.
- R-27 PASS: `/events` punya skeleton (Suspense), empty state dengan "Hapus filter", dan `error.tsx` di grup `(public)`; beranda punya "Belum ada event yang dibuka"; 404 memakai `not-found.tsx`.

- R-32 PASS: Tab berurutan sesuai tampilan dengan outline 2 px; tab detail bisa dioperasikan dengan panah, Home dan End; dialog refund menangkap fokus, tertutup dengan Escape dan mengembalikan fokus; stepper memakai `aria-disabled` sehingga fokus tidak hilang di batas.
- R-33 PASS: tidak ada skrip patch.

- R-35 PASS: build produksi dijalankan dan setiap kontrol diklik: "Hapus filter" -> `/events`; form cari + kategori -> `/events?q=jazz&category=music`; tab Deskripsi/Fasilitas -> panel berganti; "Kebijakan Refund" -> dialog terbuka, Escape menutup; "Pesan Sekarang" -> `/tickets`; "Pilih" -> stepper muncul; tombol tambah/kurang -> berhenti di batas maks dan 0; badge berubah otomatis setelah reserve; konsol tanpa error kecuali laporan 404 bawaan browser di halaman 404.
